# 🚗 Driving School Manager
 
A full-stack web application for managing driving school operations — scheduling lessons, tracking students, and enabling real-time communication between instructors and students.
 
---
 
## Tech Stack
 
| Layer | Technology |
|---|---|
| Backend | FastAPI (Python) |
| Database | NeonDB (PostgreSQL) |
| Real-time Chat | WebSockets |
| Scheduling UI | FullCalendar |
| Calendar Sync | Google Calendar API |
| Deployment | Render |
 
---
 
## Features
 
- 📅 **Lesson Scheduling** — Book and manage driving lessons via an interactive FullCalendar interface
- 🔄 **Google Calendar Sync** — Lessons sync bidirectionally with Google Calendar
- 💬 **Real-time Chat** — WebSocket-powered messaging between instructors and students
- 👤 **Student Management** — Track student progress, lesson history, and status
- 🗃️ **Persistent Storage** — PostgreSQL via NeonDB for reliable, serverless data storage
